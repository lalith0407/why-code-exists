## Inputs
- `eval/unseen/uNN/error.txt`: user-style report written only from the public symptom text (issue/PR "before"/problem
  section), with file, function and fix names removed. Wrapped by `scripts/eval/report-to-error.mjs` as before; zero frames,
  so LOCATE runs.
- Repo: the agent PR's merge commit (`agent_merge_sha`), or the fix PR base sha if the merge commit isn't reachable.
- Transcript: no public agent session exists for these PRs. The product's transcript will be derived from the agent PR
  only (title + body as the assistant's message, each file's diff as an edit tool call), by one generic converter written
  before the first run and committed with its own hash; no hand edits per case. This is a weaker input than the v4 sessions
  and is disclosed with the result.
- Ground truth is in `eval/unseen-ground-truth/` (fix PR JSON + diff, `fix-lines-unseen.json` generated by
  `scripts/eval/unseen-gt.py`) and is never given to Cursor or to the product.

## Metrics (same as docs/locate-results.md / docs/locate-eval-rule.md)
Locate top-1 / top-3 hit (file suffix match, within 10 lines of a fix line, after content re-anchoring); linker found the
edit; verified (before → after repair); grounded (frozen grade.py with fix-lines-unseen.json); correct cause (read, single
reader, against the fix PR). Configs A (layer 1 only) and B-anthropic; B-nemotron optional. One run per config, at most one
retry per case for a network error, disclosed. Run once on the pre-fix code (`pre-locate-fix-2026-10-25`) and once on the
fixed code, same inputs.

## Pass rule
The fix "helps" only if, on the same 8 cases, the fixed code beats the pre-fix code on locate top-3 hit AND correct cause in
B-anthropic, with no regression on the 15 dev cases' grounded count. Headline is out of 8; the Python/TS subset (u01–u04,
u06) is shown separately. u07 is expected to be unreachable for an edit-scoped locator and counts as a miss.
No changes to these inputs, ground truth or this rule after this tag.

## Addendum (written before any run, at tag `unseen-adapter-frozen`)
- Transcript adapter: `scripts/eval/pr-to-transcript.py` (generic). Outputs frozen in `eval/unseen/transcripts/`. Line 1 is a
  fixed neutral user line (the request isn't public), line 2 is the PR title + body, then one `apply_patch` message per file.
  u01's diff was rebuilt from the GitHub per-file API (all 322 files had patches).
- **Deviation, disclosed:** repo = the fix PR's base sha (the code in production when the error was reported), not the agent
  merge sha. Reason: the ground-truth lines are defined at the fix base sha, so grading needs that tree. The agent's edit-time
  line numbers can drift from it, which is exactly what fix 2 targets. For u08 the two shas are the same.
- Runner `scripts/eval/unseen-eval.sh`, grader `scripts/eval/unseen-grade.py` (= `locate-grade.py` with paths as arguments,
  same logic and the same frozen grade.py).
